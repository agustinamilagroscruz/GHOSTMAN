# GhostMan

Juego web tipo Pac-Man con dos modos de juego (Pacman y GhostMan), desarrollado con Next.js y React.
La especificación completa está en [TP/entrega-01.md](TP/entrega-01.md) y el plan de trabajo de la V1 en [Workflow/v1-workflow.md](Workflow/v1-workflow.md).

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).
